## About the Write-ups

Each challenge write-up aims to include:

- **Challenge Overview:** Category, points, and challenge description.
- **Initial Observations:** Files, hints, artifacts, and clues provided.
- **Solution Methodology:** A step-by-step explanation of the solving process.
- **Tools and Commands:** Relevant utilities, scripts, and commands.
- **Flag:** The verified flag, where publishing is permitted.
- **Key Takeaways:** Concepts learned and techniques used.

## Categories Covered

- **Steganography:** Discovering information hidden within images and other media.
- **Web Exploitation:** Investigating web application vulnerabilities in an authorized CTF environment.
- **OSINT:** Gathering and connecting information from publicly available sources.
- **Cryptography:** Analyzing encodings, ciphers, and cryptographic techniques.
- **Reverse Engineering:** Understanding program behavior through code and binary analysis.
- **Miscellaneous:** Solving challenges that span general technical problem-solving.
- **PWN:** Exploring binary exploitation in an authorized CTF environment.
- **Sanity:** Introductory challenges and event-orientation tasks.

## Purpose

The purpose of this repository is to document the problem-solving process, preserve useful learning notes, and help other cybersecurity learners understand the techniques behind each challenge.

## Disclaimer

These write-ups are intended for educational purposes and authorized CTF practice. Challenge details and flags should be shared only in accordance with the event's rules. All techniques should be used only on systems you own or are explicitly authorized to test.
